# Project-1-CS-472

This project is about making a supervised machine learning model that is trained on old loan application data in a goal to classify credit risks. Credit risk classification is specifically important for banks and other financial institutions as it assists them in figuring out whether or not a borrower is likely to pay back a loan (or not). Machine learning models can help analysts make better lending decisions by finding patterns in data of past borrowers. The goal of this project is to teach classification models how to tell if a loan applicant is high risk or low risk by assessing their financial and demographic information.

The dataset for this project has 148,671 rows and 34 columns. Each row is a loan application, and each column is a feature that describes the borrower or the loan. The dataset has information like income, credit score, loan amount, property value, and loan type. There are a lot of things that are very important in figuring out credit risk. A borrower's credit score is a good way to get a gist of how someone has handled money in the past and how likely they are to pay back their debts. The borrower's income shows how well they can pay back the loan over time. The Loan-to-Value (LTV) ratio demonstrates how much of the property's value is covered by the loan. This shows how much financial risk the lender is taking. The amount of the loan is also crucial because it’s usually harder to pay back larger loans. The Status column is the target variable for this project. A value of 1 means that the borrower is more likely to default on the loan, while a value of 0 means that the borrower is probably likely to pay it back.

The dataset was cleaned and set up before the models were trained. To keep the model training process from being biased we made sure to remove duplicate rows. We also looked for missing values within the dataset and filled in any missing numbers with the average of their columns. Using the average keeps the data's distribution stable and prevents mistakes from happening during the training of the model. These steps made sure that the dataset remained consistent and could actually be used by models.

We used label encoding to change the variables of categories like gender, loan type, and region into numbers, that way models could use them. Standardization was also used to scale the features so that the ranges of the numerical variables were the same. This step is especially important for models like Logistic Regression and Support Vector Machines as it prevents variables with big numbers from having too much of an influence over the model. After that, the dataset was split into two different parts, one for training purposes and another for testing purposes. The training set had 80% of the data and the testing set had 20%. 

This project used two classification models: Support Vector Machine (SVM) and Logistic Regression. Logistic Regression predicts the probability that a borrower falls into a certain risk group, while the SVM model tries to find the best decision boundary between the two groups. After training both models on the training dataset, we used accuracy and confusion matrices to see how they performed on the testing dataset. The SVM model had an accuracy of around 0.769, while the Logistic Regression model had a higher accuracy of about 0.784. The confusion matrices showed that Logistic Regression was better at finding high-risk borrowers than SVM, which usually put most applicants in the low-risk category. The confusion matrices are attached to the repo. 

Logistic Regression tended to do a little better than the SVM for classifying credit risk, according to the results. It’s better at finding borrowers that are considered “high risk” and it also has a higher accuracy rate, which makes it more suitable for helping banks and other financial institutions in finding potential loan defaults. This project shows how supervised machine learning can be used on financial data to make credit risk assessments better and help people make better lending decisions.
